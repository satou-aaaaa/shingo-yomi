# 信号よみ（shingo-yomi）

信号の意味（歩行者・車・自転車・路面電車が、何をしてよいか）を読んで、どの信号（青・黄・赤の灯火、人の形の青・青の点滅・赤、青の矢印・黄の矢印、黄の点滅・赤の点滅）かを当てる1日5問の学習ゲーム。正解したら「この信号で、歩行者は？」も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/shingo-yomi/>

- 中身は、e-Gov 法令検索「道路交通法施行令」第2条（信号の意味。<https://laws.e-gov.go.jp/law/335CO0000000270>）に書いてあることだけです（2026-09-01 施行の版を 2026-11-17 に読みました）。
- 実際の道では、信号・標識・警察官の指示に従い、まわりの安全を確かめてください。
